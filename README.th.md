# 💰 JNP Wealth Tracker

🌐 [English](README.md) | **ภาษาไทย**

เว็บแอปการเงินส่วนตัว บันทึก **รายรับ รายจ่าย และพอร์ตการลงทุน** ในแดชบอร์ดเดียว
เขียนด้วย HTML, CSS และ JavaScript ล้วน — ไม่ต้อง build ไม่มี backend ไม่ต้องสมัครสมาชิก

ข้อมูลทั้งหมดเก็บใน **เบราว์เซอร์ของคุณ (localStorage)** ไม่ถูกส่งออกไปไหน (ยกเว้นการดึงราคาล่าสุด ดูด้านล่าง)

## ✨ ฟีเจอร์หลัก

| แท็บ | รายละเอียด |
|------|-----------|
| 📊 **แดชบอร์ด** | สรุปรายรับ รายจ่าย ยอดคงเหลือรายเดือน กราฟเปรียบเทียบรายเดือน กราฟสัดส่วนรายจ่ายตามหมวด รายการล่าสุด และภาพรวมพอร์ตแบบย่อ |
| 🧾 **รายรับรายจ่าย** | เพิ่ม/แก้ไข/ลบรายการตามหมวดหมู่ ตารางแบ่งหน้า กรองตามเดือน |
| 📈 **พอร์ตการลงทุน** | ติดตามหุ้น ETF และทองคำ ทั้งจำนวน ต้นทุน ราคาปัจจุบัน และกำไร/ขาดทุนเป็นบาท เพิ่ม/แก้ไขสินทรัพย์ได้ และ **ซิงก์ราคาล่าสุด** ของหุ้นสหรัฐ ทองคำ และอัตราแลกเปลี่ยน USD/THB |
| 🗂️ **จัดการข้อมูล** | นำเข้าจากไฟล์ Excel (`.xlsx`) สำรอง/กู้คืนข้อมูลทั้งหมดเป็น JSON |

รายละเอียดอื่น ๆ:
- รองรับสินทรัพย์สกุลเงินบาทและดอลลาร์ (แปลงด้วยอัตรา USD/THB)
- กราฟด้วย Chart.js
- มีข้อมูลตัวอย่างให้ลองใช้ทันที

## 🛠️ เทคโนโลยีที่ใช้

- HTML5, CSS3, JavaScript (ES6+)
- [Chart.js](https://www.chartjs.org/) — กราฟ
- [SheetJS (xlsx)](https://sheetjs.com/) — นำเข้า Excel
- Google Fonts: Outfit และ Noto Sans Thai
- `localStorage` ของเบราว์เซอร์

## 🚀 วิธีใช้งาน

ไม่ต้องติดตั้งอะไรเพิ่ม

```bash
git clone https://github.com/jetniphat1234za-coder/Income-and-Expenses.git
cd Income-and-Expenses
```

จากนั้นเปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย หรือรันเซิร์ฟเวอร์ในเครื่อง:

```bash
python -m http.server 8000
```

แล้วเข้า <http://localhost:8000>

> ต้องเชื่อมต่ออินเทอร์เน็ตสำหรับโหลด Chart.js, SheetJS, Google Fonts (จาก CDN) และซิงก์ราคา

## 📥 การนำเข้า Excel

ในแท็บ **จัดการข้อมูล** อัปโหลดไฟล์ `.xlsx` ระบบจะหาชีตตามชื่อดังนี้

- ชีตที่ชื่อมี `สรุปข้อมูลรายเดือน` → นำเข้ารายรับ/รายจ่าย
- ชีตที่ชื่อมี `สรุปข้อมูลการออม` → นำเข้าพอร์ตการลงทุน

## 💾 สำรองและกู้คืนข้อมูล

กด **ดาวน์โหลดไฟล์สำรองข้อมูล (.json)** ในแท็บจัดการข้อมูลเพื่อส่งออกทั้งหมด และใช้ปุ่มนำเข้าเพื่อกู้คืน
การล้างข้อมูลเบราว์เซอร์จะทำให้ข้อมูลหาย ควรสำรองเป็นระยะ

## 📁 โครงสร้างโปรเจกต์

```
Income-and-Expenses/
├── index.html        # โครงหน้าเว็บและแท็บ
├── style.css         # สไตล์
├── app.js            # state, การแสดงผล, กราฟ, พอร์ต, การเก็บข้อมูล
└── xlsx_helper.js    # ตัวอ่านไฟล์ Excel (.xlsx)
```

## ⚠️ ข้อควรทราบ

- ราคาล่าสุดดึงจาก endpoint สาธารณะของ Yahoo Finance โดยตรงจากเบราว์เซอร์ อาจถูกบล็อกด้วย CORS หรือ rate limit ถ้าดึงไม่ได้จะใช้ราคาที่บันทึกไว้ล่าสุด
- ข้อมูลและพอร์ตตัวอย่างที่มากับแอปเป็นเพียงตัวอย่าง ควรแทนที่ด้วยข้อมูลของคุณ
- ข้อมูลผูกกับเบราว์เซอร์/เครื่องนั้น ๆ ใช้ไฟล์สำรอง JSON เพื่อย้ายเครื่อง
